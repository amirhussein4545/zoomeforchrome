# Zoom Box Pro - افزونه حرفه‌ای زوم صفحه (نسخه 8.6.0)
### مجهز به لایه ایزوله کامل CSS با Shadow DOM و استاندارد رسمی موزیلا webextension-polyfill

افزونه زوم تمام‌صفحه با کشیدن کادر موس، کلیک تک‌نقطه‌ای و ترنزیشن بازگشت تدریجی و نرم بدون نیاز به رفرش صفحه.

---

## 🛡️ مزیت لایه ایزوله CSS با Shadow DOM:
در این نسخه، تمام اجزای رابط کاربری افزونه (شامل پنل شناور، نوار وضعیت زوم، کادر انتخاب و اورلی) درون یک **Shadow Root ایزوله (`attachShadow({ mode: 'open' })`)** رندر می‌شوند:
- **عدم تداخل استایل‌ها:** استایل‌های وب‌سایت‌های مختلف (مانند ریست‌های CSS، بوت‌استرپ، تیلویند و فونت‌ها) هیچ‌گونه تاثیری بر ظاهر دکمه‌ها، فونت، اسلایدر و رنگ پنل نخواهند داشت.
- **عدم نشت CSS به سایت:** استایل‌های افزونه به هیچ عنوان به المان‌های صفحه میزبان نشت نمی‌کند و چیدمان صفحات حفظ می‌شود.
- **تضمین پایداری ظاهر:** ظاهر پنل در تمامی سایت‌ها (گوگل، ویکی‌پدیا، فروشگاه‌ها و سایت‌های فارسی) کاملاً یکدست و بدون به‌هم‌ریختگی باقی می‌ماند.

---

## ⚡ مزیت استفاده از `webextension-polyfill`:
این نسخه از کتابخانه رسمی `webextension-polyfill` ساخت موزیلا استفاده می‌کند. به این ترتیب:
- تفاوتهای پیاده‌سازی API مرورگرها (مانند `browser.storage` در فایرفاکس در برابر `chrome.storage` در کروم) به طور کامل یکپارچه و حل شده است.
- تمام فراخوانی‌ها به صورت Promise و async/await استاندارد اجرا می‌شوند.
- نیازی به کدهای دستی `typeof chrome` یا `typeof browser` نبوده و سازگاری یکپارچه در تمامی مرورگرها تضمین شده است.

## 🦊 راهنمای تست و نصب در موزیلا فایرفاکس (Firefox)

1. مرورگر **Firefox** را باز کرده و به آدرس زیر بروید:
   ```text
   about:debugging#/runtime/this-firefox
   ```
2. روی دکمه **Load Temporary Add-on...** کلیک کنید.
3. فایل **`manifest.json`** را از داخل پوشه افزونه انتخاب نمایید.
4. **نکته بسیار مهم برای تست:** 
   فایرفاکس اجرای افزونه‌ها را روی صفحات داخلی خودش (مثل `about:debugging`، `about:config` و فروشگاه افزونه‌ها `addons.mozilla.org`) به دلایل امنیتی قفل می‌کند.
   **حتماً یک تب جدید باز کرده و وارد یک وب‌سایت عادی (مانند `google.com`، `wikipedia.org` یا `varzesh3.com`) شوید.**
5. روی آیکون افزونه در بالای نوار ابزار فایرفاکس کلیک کنید و دکمه **«✏️ شروع انتخاب و رسم کادر زوم»** را بزنید، یا کلید میانبر **`Ctrl + Shift + Z`** را فشار دهید.
6. کادر زوم را با موس روی صفحه بکشید (یا روی نقطه دلخواه کلیک کنید) تا زوم فوری و روان اجرا شود.
7. با زدن کلید **`Escape`** یا کلیک روی دکمه **«بازگشت نرم»** صفحه بدون پرش به حالت اول بازمی‌گردد.

---

## 🌐 راهنمای نصب در گوگل کروم، بریو و اج (Chrome / Brave / Edge)

1. مرورگر کروم را باز کنید و وارد آدرس زیر شوید:
   ```text
   chrome://extensions
   ```
2. گزینه **Developer mode** را در بالا سمت راست فعال کنید.
3. روی دکمه **Load unpacked** کلیک کرده و پوشه افزونه را انتخاب کنید.
