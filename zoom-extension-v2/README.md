# Zoom Box Pro - افزونه زوم حرفه‌ای صفحه (نسخه 6.0.0)

## ویژگی‌های جدید نسخه 6.0.0

✅ **بدون نیاز به رفرش صفحه** - افزونه بلافاصله پس از نصب کار می‌کند  
✅ **امکان اسکرول بعد از زوم** - دیگر قفل نمی‌شوید و می‌توانید آزادانه اسکرول کنید  
✅ **پنل تنظیمات جمع‌شونده** - با دکمه ▼/▲ باز و بسته می‌شود  
✅ **کنترل کامل از پنل** - تغییر سطح زوم، رنگ و شفافیت بدون شورت‌کات  
✅ **تزریق خودکار استایل‌ها** - نیازی به فایل CSS جداگانه نیست  
✅ **آپدیت موقعیت هنگام اسکرول** - ناحیه زوم شده با اسکرول آپدیت می‌شود  

## نصب افزونه

1. مرورگر کروم را باز کنید
2. به آدرس `chrome://extensions/` بروید
3. گزینه **Developer mode** را در بالا سمت راست فعال کنید
4. روی **Load unpacked** کلیک کنید
5. پوشه `zoom-extension-v2` را انتخاب کنید

## نحوه استفاده

### فعال‌سازی زوم:
1. روی آیکون افزونه کلیک کنید تا پنل نمایش داده شود
2. دکمه **"🔍 فعال کردن زوم"** را بزنید
3. با موس یک کادر دور ناحیه مورد نظر بکشید
4. صفحه به صورت خودکار زوم می‌شود

### کنترل‌های پنل:
- **▼/▲** - بستن/باز کردن پنل تنظیمات
- **🔍 فعال کردن زوم** - شروع حالت کشیدن کادر
- **❌ غیرفعال کردن** - خروج از حالت زوم
- **سطح زوم** - اسلایدر برای تغییر مقدار زوم (1.5x تا 5x)
- **رنگ کادر** - انتخاب رنگ کادر انتخاب
- **شفافیت پس‌زمینه** - تنظیم میزان تاریکی پس‌زمینه هنگام زوم
- **ذخیره تنظیمات** - ذخیره تنظیمات فعلی
- **بازنشانی** - بازگشت به تنظیمات پیش‌فرض

### شورت‌کات‌های پیش‌فرض:
- `Ctrl+Shift+Z` - فعال/غیرفعال کردن زوم
- `Ctrl+Shift+R` - بازنشانی زوم
- `Esc` - خروج از حالت زوم

## نکات مهم

- بعد از زوم می‌توانید آزادانه اسکرول کنید
- پنل تنظیمات همیشه در دسترس است و نیاز به باز کردن پاپ‌آپ نیست
- تمام تغییرات بلافاصله اعمال می‌شوند
- تنظیمات شما در حافظه کروم ذخیره می‌شود

## رفع مشکل

اگر افزونه کار نکرد:
1. به `chrome://extensions/` بروید
2. افزونه را پیدا کرده و دکمه Refresh را بزنید
3. صفحه مورد نظر را رفرش کنید (فقط بار اول)
