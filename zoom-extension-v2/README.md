# Zoom Box Pro (نسخه 8.7.0) — بهینه‌شده برای موزیلا فایرفاکس 🦊

افزونه زوم تمام‌صفحه با رسم کادر موس، کلیک تک‌نقطه‌ای و بازگشت نرم و تدریجی — بدون نیاز به رفرش صفحه.
مجهز به **ایزولاسیون کامل CSS با Shadow DOM** و کاملاً سازگار با **Firefox (MV3)**؛ روی Chrome / Brave / Edge نیز کار می‌کند.

## ✨ ویژگی‌ها
- **رسم کادر زوم** با ماوس یا لمس (Pointer Events) + زوم با یک کلیک ساده
- **Shadow DOM ایزوله**: استایل افزونه هیچ‌وقت با استایل سایت میزبان تداخل نمی‌کند و بالعکس
- **انیمیشن روان سخت‌افزاری (GPU)** برای زوم و بازگشت تدریجی به ۱۰۰٪
- **میانبرهای قابل تنظیم** + کلیدهای `+` / `-` / `0` و `Esc` در حالت زوم
- **جابجایی (Pan)** در حالت زوم با کلیک وسط موس یا `Space + Drag`
- **حالت ذره‌بین (Lens HUD)** برای دیدن درصد زوم هنگام انتخاب ناحیه
- **بدون جمع‌آوری هیچ داده‌ای** — همه تنظیمات فقط به‌صورت محلی ذخیره می‌شوند

## ⌨️ میانبرها (پیش‌فرض)
| کلید | عملکرد |
|---|---|
| `Ctrl + Shift + Z` | فعال/غیرفعال کردن حالت رسم کادر زوم |
| `Ctrl + Shift + X` | بازنشانی زوم |
| `Esc` | لغو رسم / بازگشت نرم به ۱۰۰٪ |
| `+` و `-` | تغییر زوم به میزان ۲۵٪ (در حالت زوم) |
| `0` | بازگشت به ۱۰۰٪ (در حالت زوم) |
| کلیک وسط یا `Space + Drag` | جابجایی صفحه در حالت زوم |

> میانبر فعال‌سازی از داخل پاپ‌آپ افزونه قابل تغییر است (کلید و Modifierها).

## 🦊 نصب در موزیلا فایرفاکس
1. فایرفاکس را باز کرده و به آدرس زیر بروید:
   ```
   about:debugging#/runtime/this-firefox
   ```
2. روی **Load Temporary Add-on...** کلیک کنید.
3. فایل **`manifest.json`** را از داخل همین پوشه انتخاب کنید.
4. **مهم:** فایرفاکس روی صفحات داخلی خودش (`about:*` و `addons.mozilla.org`) اجازه اجرای افزونه را نمی‌دهد.
   یک تب جدید باز کنید و وارد یک سایت عادی (مثل `wikipedia.org` یا `google.com`) شوید.
5. روی آیکون افزونه کلیک کنید و **«فعال کردن زوم»** را بزنید یا `Ctrl + Shift + Z` را فشار دهید و کادر را بکشید.

## 🌐 نصب در کروم / بریو / اج
1. وارد `chrome://extensions` شوید.
2. **Developer mode** را روشن کنید.
3. روی **Load unpacked** کلیک کرده و همین پوشه را انتخاب کنید.

> نکته: مانیفست این پوشه مخصوص فایرفاکس است (`background.scripts`). برای نصب روی کروم،
> در نسخه ZIP دانلود‌شده از وب‌اپ همراه، فایل `manifest-chrome.json` قرار دارد؛
> آن را جایگزین `manifest.json` کنید (تنها تفاوت: `background.service_worker`).

## 🛠 تغییرات نسخه 8.7.0
- رفع باگ مسدود شدن کلیک‌های صفحه پس از زوم (هاست Shadow DOM دیگر رویدادها را بلع نمی‌کند)
- حذف `contain: layout` که چینش `position: fixed` داخل Shadow DOM فایرفاکس را مختل می‌کرد
- فعال شدن Pan با `Space + Drag` (قبلاً به API ناموجود وابسته بود)
- عدم تداخل میانبر افزونه با فیلدهای متنی (مثلاً Redo فایرفاکس با `Ctrl+Shift+Z`)
- خروج امن مقادیر پویا از `innerHTML` و افزودن `data_collection_permissions` (استاندارد جدید موزیلا)
- اجازه تنظیم زوم تا ۵۰٪ در پنل شناور (هماهنگ با پاپ‌آپ)
