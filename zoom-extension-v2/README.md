# Zoom Box Pro v5.0 - نسخه جدید با پنل تنظیمات جمع‌شونده

## ویژگی‌های جدید در نسخه 5.0

### 1. پنل تنظیمات جمع‌شونده (Inline Settings Panel)
- **بستن و باز کردن پنل**: دکمه‌ای در بالای پنل برای بستن/باز کردن تنظیمات
- **صرفه‌جویی در فضا**: وقتی پنل بسته است، فضای کمتری اشغال می‌کند
- **دسترسی سریع**: همچنان می‌توانید به سرعت به تنظیمات دسترسی داشته باشید

### 2. کنترل شفافیت پس‌زمینه هنگام زوم
- **تنظیم شفافیت**: اسلایدر جدید برای کنترل شفافیت پس‌زمینه مشکی هنگام زوم
- **پس‌زمینه تیره‌تر**: مقدار پیش‌فرض از 0.3 به 0.7 تغییر کرده تا تمرکز بیشتری روی ناحیه زوم شده باشد
- **مقادیر قابل تنظیم**: از 0 (کاملاً شفاف) تا 1 (کاملاً مشکی)

### 3. بهبودهای رابط کاربری
- **هدر پنل**: اضافه شدن هدر با عنوان و دکمه جمع‌شونده
- **انیمیشن‌ها**: انتقال نرم بین حالت‌های باز و بسته
- **استایل collapsed**: وقتی پنل بسته است، استایل متفاوتی دارد

## نحوه استفاده

### نصب
1. باز کردن Chrome و رفتن به `chrome://extensions/`
2. فعال کردن "Developer mode" در گوشه بالا سمت راست
3. کلیک روی "Load unpacked"
4. انتخاب پوشه `zoom-extension-v2`

### استفاده از افزونه
1. کلیک روی آیکون افزونه برای فعال کردن
2. کشیدن کادر روی ناحیه مورد نظر برای زوم
3. استفاده از پنل تنظیمات روی صفحه:
   - **دکمه ▼/▲**: بستن/باز کردن پنل
   - **سطح زوم**: تنظیم میزان بزرگنمایی
   - **رنگ کادر**: انتخاب رنگ کادر انتخاب
   - **شفافیت پس‌زمینه**: تنظیم تاریکی پس‌زمینه هنگام زوم
   - **شورت‌کات‌ها**: تنظیم کلیدهای میانبر

### شورت‌کات‌های پیش‌فرض
- **Ctrl+Shift+Z**: فعال/غیرفعال کردن زوم
- **Ctrl+Shift+R**: بازنشانی زوم
- **Escape**: خروج از حالت زوم

```
└── icons/              # آیکون‌های افزونه

```

## نکات فنی

### تغییرات در background.js
- به‌روزرسانی نسخه به 5.0.0
- تغییر مقدار پیش‌فرض overlayColor به `rgba(0, 0, 0, 0.7)`

### تغییرات در content.js
- اضافه شدن `isPanelOpen` برای ردیابی وضعیت پنل
- اضافه شدن متد `togglePanel()` برای بستن/باز کردن پنل
- اضافه شدن UI جدید برای هدر پنل و دکمه جمع‌شونده

### تغییرات در styles.css
- اضافه شدن کلاس `.zoom-controls.collapsed` برای حالت بسته
- اضافه شدن `.zoom-controls-header` برای هدر پنل
- اضافه شدن `.zoom-btn-small` برای دکمه کوچک بستن
- اضافه شدن `.zoom-panel-title` برای عنوان پنل
- اضافه شدن `.zoom-settings-content` برای محتوای قابل جمع‌شدن
