# Zoom Box Pro — زوم حرفه‌ای صفحه 🦊

افزونه مرورگر **بهینه‌شده برای موزیلا فایرفاکس** (سازگار با Chrome/Brave/Edge) برای زوم تمام‌صفحه
با رسم کادر انتخابی، انیمیشن روان و ایزولاسیون کامل استایل با Shadow DOM — نسخه **8.7.0**.

این مخزن دو بخش دارد:

| مسیر | توضیح |
|---|---|
| `zoom-extension-v2/` | سورس کامل افزونه (Manifest V3 مخصوص فایرفاکس) — بدون نیاز به بیلد، مستقیم قابل نصب |
| `src/` (وب‌اپ React/Vite) | محیط آزمایش (Sandbox) تعاملی برای تست موتور زوم + مشاهده سورس افزونه و دانلود ZIP نصب |

## 🦊 نصب سریع در فایرفاکس
1. به آدرس `about:debugging#/runtime/this-firefox` بروید.
2. روی **Load Temporary Add-on...** کلیک کنید و فایل `zoom-extension-v2/manifest.json` را انتخاب کنید.
3. یک تب معمولی (مثلاً `wikipedia.org`) باز کنید و `Ctrl + Shift + Z` را بزنید، سپس کادر بکشید.

راهنمای کامل‌تر: [`zoom-extension-v2/README.md`](zoom-extension-v2/README.md)

## 🧪 اجرای محیط آزمایش (Sandbox)
```bash
npm install
npm run dev      # http://localhost:3000
```

- تب **«محیط آزمایش»**: تست موتور زوم روی نمونه‌صفحات مختلف (مقاله، نمودار، نقشه، کد)
- تب **«محتوای دلخواه»**: بارگذاری تصویر/متن خودتان برای تست
- تب **«فایل‌ها و راهنمای نصب»**: مشاهده سورس واقعی افزونه + دانلود ZIP آماده نصب
