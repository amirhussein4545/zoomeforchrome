# افزونه کروم Zoom Box - زوم با کشیدن کادر

یک افزونه کروم که به شما امکان می‌دهد با کشیدن یک کادر روی هر قسمت از صفحه، روی آن ناحیه زوم کنید.

## 📁 ساختار فایل‌ها

```
zoom-extension/
├── manifest.json       # فایل پیکربندی افزونه
├── background.js       # سرویس ورکر پس‌زمینه
├── content.js          # اسکریپت اصلی زوم
├── styles.css          # استایل‌های UI
├── popup.html          # صفحه پاپ‌آپ راهنما
└── icons/              # آیکون‌های افزونه
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 🚀 نحوه نصب

### مرحله ۱: باز کردن حالت توسعه‌دهنده در کروم
1. مرورگر کروم را باز کنید
2. به آدرس `chrome://extensions/` بروید
3. در گوشه بالا راست، گزینه **Developer mode** (حالت توسعه‌دهنده) را فعال کنید

### مرحله ۲: بارگذاری افزونه
1. روی دکمه **Load unpacked** (بارگذاری بسته نشده) کلیک کنید
2. پوشه `zoom-extension` را انتخاب کنید
3. افزونه باید حالا در لیست افزونه‌های شما ظاهر شود

### مرحله ۳: سنجاق کردن افزونه (اختیاری)
1. روی آیکون پازل در نوار ابزار کروم کلیک کنید
2. افزونه "Zoom Box" را پیدا کنید
3. روی آیکون سنجاق کلیک کنید تا به نوار ابزار اضافه شود

## 📖 راهنمای استفاده

### روش استفاده:
1. **کلیک روی آیکون افزونه** - در نوار ابزار کروم روی آیکون ذره‌بین کلیک کنید
2. **فعال کردن زوم** - در پنل باز شده، دکمه "🔍 فعال کردن زوم" را بزنید
3. **کشیدن کادر** - با موس خود یک کادر مستطیلی دور ناحیه‌ای که می‌خواهید زوم شود بکشید
4. **زوم خودکار** - به محض رها کردن موس، صفحه به صورت خودکار روی آن ناحیه زوم می‌شود
5. **تنظیم سطح زوم** - می‌توانید با اسلایدر موجود در پنل، میزان زوم را بین 1.5x تا 5x تنظیم کنید
6. **غیرفعال کردن** - برای بازگشت به حالت عادی، دکمه "❌ غیرفعال کردن" را بزنید

### کلیدهای میانبر:
- **Escape** - خروج سریع از حالت زوم و بازگشت به حالت عادی

### ویژگی‌ها:
✅ کشیدن کادر برای انتخاب ناحیه زوم  
✅ تنظیم سطح زوم قابل تنظیم (1.5x تا 5x)  
✅ پشتیبانی از صفحات لمسی (تاچ)  
✅ انیمیشن نرم و روان  
✅ رابط کاربری زیبا و مدرن  
✅ سبک و بدون تاثیر بر سرعت مرورگر  

## 🔧 توسعه و سفارشی‌سازی

### تغییر سطح زوم پیش‌فرض
در فایل `content.js`، خط زیر را پیدا کرده و عدد را تغییر دهید:
```javascript
this.zoomLevel = 2; // عدد مورد نظر خود را وارد کنید
```

### تغییر رنگ‌ها
در فایل `styles.css` می‌توانید رنگ‌ها را تغییر دهید:
- `.zoom-selection-box` - رنگ کادر انتخاب
- `.zoom-controls` - رنگ پنل کنترل
- `.zoom-btn` - رنگ دکمه‌ها

### افزودن قابلیت‌های جدید

#### مثال: افزودن کلید میانبر سفارشی
در فایل `content.js`، در متد `addEventListeners`:
```javascript
document.addEventListener('keydown', (e) => {
  if (e.key === 'z' && e.ctrlKey) {
    this.toggleActive();
  }
});
```

#### مثال: ذخیره سطح زوم در حافظه
```javascript
// ذخیره
localStorage.setItem('zoomLevel', this.zoomLevel);

// بازیابی
const savedLevel = localStorage.getItem('zoomLevel');
if (savedLevel) {
  this.zoomLevel = parseFloat(savedLevel);
}
```

### دیباگ کردن
1. به صفحه‌ای که می‌خواهید تست کنید بروید
2. کلید F12 را بزنید تا Developer Tools باز شود
3. به تب Console بروید
4. پیام‌های لاگ افزونه را مشاهده کنید
