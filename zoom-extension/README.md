# Zoom Box - افزونه کروم زوم با کشیدن کادر

یک افزونه کروم پیشرفته و قابل توسعه که به شما امکان می‌دهد با کشیدن یک کادر روی صفحه، روی آن ناحیه زوم کنید.

## 📦 ویژگی‌های نسخه 2.0.0

### ✨ قابلیت‌های اصلی
- ✅ کشیدن کادر برای انتخاب ناحیه زوم
- ✅ تنظیم سطح زوم قابل تنظیم (1.5x تا 5x)
- ✅ تغییر رنگ کادر انتخاب
- ✅ تنظیم شفافیت پس‌زمینه
- ✅ ذخیره تنظیمات برای استفاده بعدی
- ✅ بازنشانی به تنظیمات کارخانه
- ✅ پشتیبانی از صفحات لمسی
- ✅ رابط کاربری زیبا و مدرن

### ⌨️ شورت‌کات‌های کیبورد
- **Ctrl+Shift+Z** (یا Command+Shift+Z در مک): فعال/غیرفعال کردن حالت زوم
- **Ctrl+Shift+R** (یا Command+Shift+R در مک): بازنشانی زوم
- **Escape**: خروج سریع از حالت زوم

### 🔧 شخصی‌سازی
- انتخاب رنگ دلخواه برای کادر
- تنظیم سطح شفافیت overlay
- تنظیم سطح زوم پیش‌فرض
- ذخیره خودکار تنظیمات

## 🚀 راهنمای نصب

### روش اول: Load Unpacked (توسعه)
1. باز کردن کروم و رفتن به آدرس `chrome://extensions/`
2. فعال کردن گزینه **Developer mode** در بالا سمت راست
3. کلیک روی دکمه **Load unpacked**
4. انتخاب پوشه `zoom-extension`
5. افزونه نصب شده و آماده استفاده است!

## 📖 راهنمای استفاده

### شروع سریع
1. روی آیکون افزونه (ذره‌بین بنفش) در نوار ابزار کروم کلیک کنید
2. پنل راهنما باز می‌شود
3. به صفحه‌ای که می‌خواهید زوم کنید بروید
4. از یکی از روش‌های زیر استفاده کنید:
   - روی آیکون افزونه کلیک کرده و سپس در صفحه دکمه "🔍 فعال کردن زوم" را بزنید
   - از شورت‌کات `Ctrl+Shift+Z` استفاده کنید
5. با موس یک کادر دور ناحیه مورد نظر بکشید
6. به صورت خودکار روی آن ناحیه زوم می‌شود
7. برای غیرفعال کردن:
   - دکمه "❌ غیرفعال کردن" را بزنید
   - یا کلید `Escape` را فشار دهید
   - یا از شورت‌کات `Ctrl+Shift+R` استفاده کنید

### تنظیمات پیشرفته
پس از فعال کردن زوم، پنل کنترل در بالای صفحه ظاهر می‌شود که شامل:
- **سطح زوم**: اسلایدر برای تنظیم میزان زوم (1.5x تا 5x)
- **رنگ کادر**: انتخابگر رنگ برای تغییر رنگ کادر انتخاب
- **شفافیت پس‌زمینه**: اسلایدر برای تنظیم تاریکی پس‌زمینه
- **ذخیره تنظیمات**: ذخیره تنظیمات فعلی برای استفاده‌های بعدی
- **بازنشانی**: بازگشت به تنظیمات اولیه کارخانه

## 🛠️ توسعه و شخصی‌سازی

### ساختار فایل‌ها
```
zoom-extension/
├── manifest.json      # پیکربندی افزونه
├── background.js      # سرویس ورکر پس‌زمینه
├── content.js         # اسکریپت اصلی زوم
├── styles.css         # استایل‌های UI
├── popup.html         # پنل پاپ‌آپ تنظیمات
├── README.md          # این فایل
└── icons/             # آیکون‌های افزونه
```

### تغییر تنظیمات پیش‌فرض
برای تغییر تنظیمات پیش‌فرض، فایل `background.js` را ویرایش کنید:

```javascript
const defaultSettings = {
  zoomLevel: 2,              // سطح زوم پیش‌فرض
  boxColor: '#00ff00',       // رنگ کادر
  overlayColor: 'rgba(0, 0, 0, 0.3)',
  shortcutEnabled: true,
  animationDuration: 0.3
};
```

### تغییر شورت‌کات‌ها
1. به آدرس `chrome://extensions/shortcuts` بروید
2. افزونه Zoom Box را پیدا کنید
3. شورت‌کات‌های دلخواه را تنظیم کنید

## 🎨 سفارشی‌سازی CSS

```css
/* تغییر رنگ گرادینت پنل کنترل */
.zoom-controls {

```

## 🐛 رفع مشکلات

### مشکل: Manifest file is missing or unreadable
**راه حل**: مطمئن شوید که پوشه `zoom-extension` را لود کرده‌اید، نه پوشه والد آن.

### مشکل: افزونه کار نمی‌کند
**راه حل**: 
1. صفحه را رفرش کنید (F5)
2. مطمئن شوید افزونه فعال است
3. کنسول توسعه‌دهنده را بررسی کنید (F12)
