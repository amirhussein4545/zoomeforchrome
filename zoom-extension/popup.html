Zoom Box Pro - پنل کنترل

⚙️ تنظیم شورت‌کات‌ها

💡 شورت‌کات‌های خود را وارد کرده و ذخیره کنید:

فرمت: Ctrl+Shift+Z یا Alt+Ctrl+K و غیره
فرمت: Ctrl+Shift+R یا Alt+Ctrl+M و غیره

📌 شورت‌کات فعلی:
• فعال/غیرفعال: Ctrl+Shift+Z
• بازنشانی: Ctrl+Shift+R
• خروج سریع: Escape (ثابت)

📖 راهنمای استفاده

  1. به صفحه‌ای که می‌خواهید زوم کنید بروید
  2. دکمه "🔍 فعال کردن زوم" را در صفحه بزنید
  3. یا از شورت‌کات کیبورد استفاده کنید
  4. با موس یک کادر دور ناحیه مورد نظر بکشید
  5. به صورت خودکار روی ناحیه زوم می‌شود
  6. برای غیرفعال کردن، دکمه قرمز را بزنید یا Escape را فشار دهید

⌨️ شورت‌کات‌های پیش‌فرض

فعال/غیرفعال کردن زوم Ctrl+Shift+Z
بازنشانی زوم Ctrl+Shift+R
خروج سریع Escape

⚙️ قابلیت‌های شخصی‌سازی

  • تنظیم سطح زوم (1.5x تا 5x)
  • تغییر رنگ کادر انتخاب
  • تنظیم شفافیت پس‌زمینه
  • ذخیره شورت‌کات‌های سفارشی
  • ذخیره تنظیمات برای استفاده بعدی
  • بازنشانی به تنظیمات کارخانه
  • پشتیبانی از صفحات لمسی
  • تم رنگی سبز فسفری، آبی آسمانی و مشکی

🎯 نکات مهم

• برای کشیدن کادر باید حالت فعال باشد
• کادر باید حداقل 50 پیکسل باشد
• تنظیمات شما به صورت خودکار ذخیره می‌شود
• از کلید Escape برای خروج سریع استفاده کنید
• شورت‌کات‌ها را می‌توانید در همین پنل تغییر دهید
